Data quality management process

Documented end to end across six roles
Detect
  • DQ Analyst runs the monthly report and raises issues
  • DG Officer routes the request to the technical steward via IT-SR
Remediate
  • Data Custodian reviews the DQ rule and supervises implementation
  • DQ Developer implements the script and generates the report
Approve
  • Business Data Steward reviews and approves the implemented rule
  • Data Owner signs off, or returns it to remediation
